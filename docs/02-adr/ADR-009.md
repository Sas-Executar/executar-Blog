# ADR-009: Ambiente e segredos gerados por script

**Status:** Accepted
**Date:** 2026-09-23
**Deciders:** usuário (R-05)

## Context
"Env files devem nascer junto do código… evita necessidade de fazer manual." Wrangler lê `.env` (ou `.dev.vars`, nunca ambos) no dev local; produção usa `wrangler secret put`/painel; `secrets.required` faz o deploy falhar se faltar segredo.

## Decision
- Cada app versiona `.env.example` (sem valores reais).
- `scripts/setup-env.mjs` roda no `postinstall`, é idempotente e nunca sobrescreve: cria `.env` a partir do `.env.example`. Para chaves de teste do Turnstile, usa as chaves públicas de teste oficiais da Cloudflare.
- `secrets.required` nos `wrangler.jsonc` (`ANTHROPIC_API_KEY` no agente; `TURNSTILE_SECRET_KEY` no blog).
- `.gitignore` bloqueia `.env*` (exceto `.env.example`) e `.dev.vars*`; `guard` confere.

## Consequences
- `npm install` basta para ter ambiente local.
- Segredos de produção continuam exigindo o usuário (USER_ACTION_REQUIRED).
