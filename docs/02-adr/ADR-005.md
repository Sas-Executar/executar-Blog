# ADR-005: GitHub Markdown CSS + Expressive Code (tema GitHub) + tokens mínimos

**Status:** Accepted
**Date:** 2026-09-23
**Deciders:** usuário (correção "BR — Shell Editorial")

## Context
Usuário quer tabelas, listas, blockquote, código inline e tipografia de Markdown com aparência GitHub, sobre o shell Obsidian, com uma camada mínima de tokens. Três folhas de estilo sobre o mesmo conteúdo geram conflito de especificidade.

## Decision
- Override `MarkdownContent` do Starlight (API oficial) só para adicionar a classe `markdown-body` ao conteúdo.
- `github-markdown-css` importado dentro de `@layer github` (camada de menor prioridade que o tema), aplicado seletivamente: tabelas, listas, blockquote, `code` inline, tipografia. Blocos `pre` ficam com o Expressive Code.
- Expressive Code (já incluso no Starlight) com temas `github-light` / `github-dark` — só configuração.
- `tokens.css`: 10 tokens pedidos + 3 exigidos pelo HIG (ADR-006), mapeados para `--sl-*` e variáveis do GitHub CSS.

## Options Considered
| Opção | Pros | Cons |
|---|---|---|
| Camadas + escopo (escolhida) | Upstream intacto, conflito controlado | Precisa de teste visual |
| Só GitHub CSS | Visual GitHub puro | Briga com o tema e com Expressive Code |
| Tailwind Typography | Popular | Novo sistema de utilitários (proibido para o shell) |

## Consequences
- Mais fácil: atualizar os três upstreams por `npm update`.
- Revisitar: se o tema mudar nomes de variáveis.
