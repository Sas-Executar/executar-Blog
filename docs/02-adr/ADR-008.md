# ADR-008: Agente "Pergunte aos artigos" com Claude Agent SDK no Cloudflare Sandbox

**Status:** Accepted
**Date:** 2026-09-23
**Deciders:** usuário ("Agent SDK vence")

## Context
Usuário exige o Claude Agent SDK (`@anthropic-ai/claude-agent-sdk`). O SDK é o harness do Claude Code e precisa de processo com sistema de arquivos — não roda em isolate de Worker. A Cloudflare publica o template oficial `cloudflare/sandbox-sdk/examples/claude-code` (Worker + Container, credencial injetada por proxy, internet fechada).

## Decision
- `apps/agente` derivado do template oficial. O container instala o Agent SDK e roda `agente.mjs`, que chama `query()` com ferramentas **somente leitura** (Read, Grep, Glob), `cwd=/vault` (cópia do conteúdo publicado), `maxTurns` limitado, modelo `claude-opus-5`, e devolve JSON `{resposta, fontes}`.
- A chave Anthropic existe só como secret do Worker; o container vê um placeholder e o `outboundByHost` injeta a chave na saída (padrão do template). Internet do container desligada; host permitido: `api.anthropic.com`.
- Blog chama o agente por service binding, após Turnstile e limite de tamanho.
- Custos: Workers Paid (US$ 5/mês) + Containers + tokens. Spend limit no AI Gateway (configuração no painel).

## Options Considered
| Opção | Complexidade | Custo | Observação |
|---|---|---|---|
| **Agent SDK no Sandbox (escolhida)** | Med | Paid + containers | Decisão do usuário |
| API Messages direta no Worker | Low | Só tokens | Rejeitada pelo usuário |
| Claude Managed Agents on Cloudflare | High | Paid | Alpha, excesso para Q&A |

## Consequences
- Mais difícil: cold start do container; Docker necessário no build (Workers Builds suporta); não testável localmente sem Docker (este ambiente não tem).
- Revisitar: latência medida no preview; cache de respostas.
