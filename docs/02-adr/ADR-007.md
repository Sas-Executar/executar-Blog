# ADR-007: Gráficos com Apache ECharts (substitui Power BI)

**Status:** Accepted
**Date:** 2026-09-23
**Deciders:** usuário ("algo similar open source")

## Context
Power BI embed exige capacidade Fabric/Embedded (paga) e conta Microsoft; "publish to web" é público sem controle. Usuário quer alternativa open source para gráficos e análises no blog.

## Decision
Apache ECharts (Apache-2.0) via componente único `<Grafico titulo resumo dados>` em páginas MDX, carregado só quando visível (`client:visible`), com `aria.enabled`, cores dos tokens e dark mode. Dados em `src/data/graficos/*.json`. Nenhum dado fictício publicado.

## Options Considered
| Opção | Complexidade | Custo | Observação |
|---|---|---|---|
| **ECharts** | Low (1 componente) | Grátis | Dashboards interativos, acessibilidade `aria` nativa |
| Observable Plot | Low | Grátis | Menos interatividade de dashboard |
| Evidence.dev | Med | Grátis | Segundo framework/site |
| Power BI | High | Licença | Fora do Cloudflare |

## Consequences
- Um gráfico novo = um JSON + uma linha MDX.
- Revisitar: dados dinâmicos (D1) se surgir necessidade.
